# Project Idea: Freelancer Hiring App

## Problem:
Freelancers and clients struggle to connect on one trusted platform.

## Solution:
A web application where clients post jobs, freelancers apply, and both can chat and rate after work.

## Tech Stack:
- Frontend: React.js + Bootstrap
- Backend: Spring Boot + MySQL
- Tools: Postman, Git, GitHub, Render, Netlify

## Modules:
1. User Registration & Login (JWT)
2. Job Posting and Applications
3. Chat / Message System
4. Review and Rating System
